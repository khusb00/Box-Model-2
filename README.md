# Box-Model-2 # Bouncing Box Animation

A simple HTML and CSS project featuring a box that bounces up and down while changing colors from red to green, utilizing CSS keyframe animations.

# Features
- Bouncing Animation: The box animates up and down using CSS keyframe animations.
- Color Transition: The box's color smoothly transitions from red to green as it bounces.

# Technologies Used
- HTML: Defines the box element.
- CSS: Creates the bouncing animation and color transition effects using keyframes.

# How it Works
The project leverages CSS keyframe animations to define specific points in the animation sequence, allowing for a smooth bouncing effect and color transition.

# Key Highlights
- Keyframe Animations: Used to create a seamless bouncing effect and color transition.
- CSS-only Solution: No JavaScript required, showcasing the power of CSS animations.
